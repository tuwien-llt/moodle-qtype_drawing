The plugin is maintained by the Technische Universität Wien and is available at the public mirror repository <https://github.com/tuwien-llt/moodle-qtype_drawing>.

*License:*   [GNU GPL v3 or later](http://www.gnu.org/copyleft/gpl.html)

Description
-----------

The `qtype_drawing` plugin provides a drawing-based question type for Moodle.
Teachers can use it to let students create or annotate drawings directly as
part of an assessment.


Usage
-----

Use this question type when an answer should be provided as a drawing instead of
plain text. The exact workflow depends on the question settings and how the
question is embedded in the quiz.


Installation
------------

* Copy the code into the `question/type/drawing` directory of your Moodle
  installation.

* See http://docs.moodle.org/en/Installing_plugins for details on installing Moodle plugins
